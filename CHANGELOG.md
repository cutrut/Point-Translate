# Changelog

## Point & Translate — 2026-11-09

- Renamed the app to Point & Translate. Run `Start_Point_And_Translate.bat`
  to launch `point_and_translate.py`.
- Updated both READMEs to explain how to look up unfamiliar words while
  learning a language through games and visual novels.

## 5.3.3 Simple — 2026-11-08

- Renamed the application to `hover_dict.py` so the filename does not carry an
  outdated version. Both BAT entry points use the new filename.
- Centralised the displayed app version in `APP_VERSION`.
- Added the MIT license for Hover Dict, with dependency and engine licensing
  scope explained in both READMEs.
- Updated English and Vietnamese instructions, removed obsolete GitHub
  publishing notes and documented upgrades from 5.3.2.
- Added an explicit native Windows testing checklist in `TESTING.md`.

Native Windows installation, GUI, OCR, keyboard hooks and game compatibility
still require manual testing. This release does not claim to fix HOI4.

## 5.3.2 Simple

Previous simple edition: one Python app, two BAT entry points, an English
key-binding window and Latin-alphabet OCR support.
